Quick Start

To make your first API call, use the following header in your requests:

Ocp-Apim-Subscription-Key: {{SubscriptionKey}}

Example request:

curl -X POST https://{{ApiEndpoint}}/v1/stt/transcribe \
  -H "Ocp-Apim-Subscription-Key: {{SubscriptionKey}}" \
  -H "Content-Type: audio/wav" \
  --data-binary @audio.wav
